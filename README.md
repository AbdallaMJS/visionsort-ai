# VisionSort AI

Explainable computer-vision project for classifying recyclable and waste materials from images using the TrashNet dataset.

This repository is being developed as a reproducible student AI portfolio project. The goal is to compare a simple image baseline with transfer learning, evaluate class-level errors, and provide visual explanations for model predictions.

> Project status: active development. Accuracy and F1 results will be reported only after training and evaluation have actually been run.
